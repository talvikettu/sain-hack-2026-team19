# Материалы кейса 4

Папка предназначена для локальной работы team19. Родительская папка team19 исключена из Git правилом в корневом .gitignore.

Скачано 17 ноября 2026 года через PowerShell. Проверенный состав dev-набора: **20 статей, 609 разделов, 3 эксперта, 60 запросов, 60 эталонных записей, 2 профиля, 26 сообщений истории и 3 промпта проверки**.

Основные файлы:

- `openapi.json` — публичная спецификация API, скачана 17 ноября 2026 года.
- `schemas/Case4Dataset.schema.json` — схема входного набора, выделена из OpenAPI.
- `schemas/Case4Answers.schema.json` — точная схема ответа /run.
- `download_case4.ps1` — повторная загрузка через PowerShell; токен читает из соседнего api.token, не выводит его. Передаёт только документированному серверу хакатона.
- `download_dataset.py` — локальная раскладка уже скачанного набора; сеть и секреты не использует.
- `verify_data.py` — проверка полноты выгрузки, ID, ссылок эталона и SHA256.
- `API_CASE4.md` — краткая справка по доступным методам кейса 4.

Материалы:

- `articles/` — 20 статей, каждая в JSON и Markdown, с исходными ID, авторами, DOI и лицензией.
- `articles.json` — тот же корпус единым массивом.
- `sections.jsonl` — разделы для построения поискового индекса, с article_id, section_id и текстом.
- `experts/` — 3 эксперта в JSON и Markdown; `experts.json` и `experts.md` — общие файлы.
- `judge_prompts.json` — выданные промпты проверяющей модели.
- `dataset_meta.json` — метаданные набора.
- `manifest.json` — число документов и разделов, размеры и SHA256 файлов с нормализованными переводами строк LF.
- `ARTICLES_INDEX.md` — оглавление всех 20 статей.
- `raw/case4-dev-v2.json` — полный исходный ответ API с dataset и reference.
- `dataset.json` — полный входной набор отдельно.
- `reference.json` — открытый dev-эталон для локальной оценки.
- `requests.json`, `users.json`, `chat_history.json` — запросы, профили и история отдельно.
- `judge_prompts/` — каждый из трёх промптов в JSON и Markdown.
- `inventory.json` — метаданные и точные количества записей.
- `validation_report.json` — локальный результат работы `verify_data.py`.

Dev-набор включает профили, историю, вопросы и эталон для локальной разработки. Архив для стенда исключает каталог `data/`. Эталон используется для проверки результатов поиска.

Статьи — тексты разделов ровно в том виде, в котором их выдаёт API организаторов. Это не дополнительные статьи из интернета и не обещание наличия полных PDF издателей. Для цитирования используйте исходные article_id/section_id и сохраняйте атрибуцию CC BY.

Повторная загрузка из папки data:

```powershell
.\download_case4.ps1
python .\download_dataset.py
python .\verify_data.py
```

Спецификация API доступна в `openapi.json`. В `docs/` сохранён HTML-снимок страницы Swagger.
